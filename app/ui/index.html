社区主题

从 DreamSkin 社区导入

DreamSkin（dreamskin.cc）是独立的第三方主题社区，与本工具及 ZCode 官方均无关联。只有在你主动操作时，才会以只读方式访问其固定下载接口（校验大小与 SHA-256），不上传任何本地数据；不做全量同步，也不提供主题再分发。
在主题库点开喜欢的主题 → 复制它的 ver_ ID 或「一键换肤」链接 → 粘贴到这里。导入的主题出现在「皮肤管理 · 我的主题」网格，与本地主题同等使用（轮换 / 滤镜 / 预览全部可用）。
