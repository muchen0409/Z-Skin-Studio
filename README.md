# Zcode+ 管理控制台

给 ZCode 桌面客户端换肤的 GUI 启动器（Electron 应用）。通过调试端口在渲染层注入半透明皮肤：背景图垫底 + 面板透明化 + 弹窗/弹层同步，**不修改任何应用文件**，可一键恢复。

## 使用

双击 **`app\dist-new\ZCodeSkinLauncher-win32-x64\ZCodeSkinLauncher.exe`**（免安装，整个文件夹一起拷贝分发）：

- **运行状态**：「启用 Zcode 皮肤」开关（开 = 自动拉起 ZCode 并注入，关 = 恢复原样），状态每 4 秒刷新（窗口隐藏到托盘时暂停）；「连接诊断」一键逐项检查 路径→进程→端口→目标→注入→选择器，输出可读报告
- **背景滤镜与遮罩**：每主题可调 模糊 / 亮度 / 对比度 / 饱和度，以及「可读性遮罩」（轻/重两档上下渐变+暗角，浅色图上保证文字可读）；调参即时生效
- **实时预览**：皮肤已启用时点主题卡立即预览效果（临时生效），点「应用主题」才保存
- **开机自启与自动应用**：可设置开机自启（驻留托盘）与「启动后自动应用上次主题」——自动接管仅在由本启动器拉起 ZCode 时生效（调试端口由此开启）
- **全局快捷键**：`Alt+Shift+S` 切换皮肤、`Alt+Shift+N` 下一个主题（可在界面关闭）
- **我的主题**：「导入主题」支持图片（多选）和 DreamSkin 主题包 `.zip`（解析背景图 / accent 强调色 / 焦点位置 / **theme.css 对话框样式**——通过选择器映射与 `--ds-theme-color-*` 变量注入，包里对对话框、侧栏、输入栏的设计会在 ZCode 里生效）；点卡片载入草稿；每主题独立保存透明度与显示位置；`⋯` 菜单重命名 / 删除；「应用主题」注入草稿
- **托盘主题菜单**：托盘右键「切换主题」子菜单直接换肤，不必打开主窗口
- **深浅色外观**：跟随 ZCode / 强制深色 / 强制浅色，随注入生效
- **动态配色**：界面强调色优先用主题包 token，普通图片导入时自动取主色调并缓存
- **系统托盘**：关闭窗口即驻留托盘，右键可 显示主窗口 / 应用皮肤 / 恢复外观 / 退出
- **持久注入**：皮肤经 CDP 持久会话维护（刷新事件重注入 + 看门狗 + 指数退避断线重连），ZCode 内刷新页面 / 新开文档不丢失
- **主题轮换**：在主题卡 `⋯` 菜单把主题加入轮换池（卡上显示「轮换」角标），设置行开启轮换并选择间隔（1 分钟 ~ 每天）与顺序/随机；仅当皮肤已启用时才会轮换，切换在持久会话上热切换
- **ZCode 版本管理**（独立页面）：显示当前 ZCode 版本号（从 app.asar 读取）与安装路径；「检查更新」多源探测——先查 ZCode 自带配置的更新源，不可达时自动查开源仓库 github.com/zai-org/ZCode 的最新 Release 并比对版本；「关于」卡片可打开诊断日志目录

## 开发

```bat
cd app
npm install          安装依赖（electron、ws、adm-zip 等）
npx electron .       开发运行
npm run dist         打包 exe 到 app\dist-new\
```

代码结构：`main.js`（生命周期 / GPU 开关 / ZCode 启动）+ `src\`（配置、CDP、换肤引擎、主题包、版本、轮换、IPC）+ `ui\`（index.html / styles.css / renderer.js）。

## 常见问题

- **提示未开启调试端口**：ZCode 正以普通方式运行，请完全退出（含托盘）后从启动器启用
- **提示端口等待超时**：该版本 ZCode 可能禁用了调试开关
- **未找到 ZCode.exe**：在界面「更改 ZCode 路径」手动指定；或设置环境变量 `ZCODE_EXE` 指向 ZCode.exe（自动探测会依次尝试 `%LOCALAPPDATA%\Programs\ZCode`、`C:\Program Files\ZCode`）。主题包回填的扫描目录可用 `ZCODE_THEME_DIRS` 扩展（分号分隔）
- **首次运行被 SmartScreen 拦截**：exe 未签名，点「更多信息 → 仍要运行」
- **恢复原始外观**：只移除注入层；深浅色若为强制模式，切回「跟随 ZCode」再应用一次即可归还控制权
- **窗口黑屏 / 花屏**（少数显卡）：在 exe 同目录的 `resources\app\` 下新建空文件 `gpu-off.flag` 后重启，即回到软件渲染（界面会自动降低毛玻璃效果）；删除该文件恢复 GPU 加速
- **皮肤掉了想查原因**：「连接诊断」一键定位断点（哪一步失败、怎么修）；或「版本管理 → 关于 → 打开日志目录」看 `diag.log`
- **ZCode 升级后皮肤失效**：诊断报告会显示关键选择器命中率（`#root` / `#content section` / `#sidebar` / 输入框 / 消息面），命中率归零说明 ZCode 界面结构变化，状态栏会主动出现 ⚠ 提示；选择器兼容性修复随本工具版本更新

## 安全声明

非官方第三方工具。调试端口仅在通过本启动器启用皮肤时拉起 ZCode 才开启；注入内容只有装饰性 CSS 与主题偏好键（localStorage `zcode-theme`），不读取、不上传任何聊天数据；导入的主题包在内存中解析，文件名经白名单与越界校验；配置写入为原子替换（写一半断电不会损坏 config.json，损坏时自动从 .bak 恢复）。
